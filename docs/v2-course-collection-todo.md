> ⚠ 两个实测教训（下轮改课程页前先看）：
> 1. **产物与源文件的行尾不同**：`assets/*.js|css` 是 LF，而生成链（`course_site.py` 文本模式

- **背景**：C2 硬约束（单讲独立）下的有意取舍；但读者点进讲次后只能浏览器后退。
- **三个候选方案**（都须满足「可选、不默认、不构成依赖」，§7 曾否决「讲次依赖课程目录」）：
  1. 单讲构建加可选参数 `--course-home <相对路径>`（默认不注入）；
  2. 课程页的讲次链接改 `target="_blank"`（课程页标签永不丢失；代价是标签管理）；
  3. 讲次页顶部注入中性提示行（无链接、零依赖）。
- **落点**：方案 1 → `build.py`；方案 2 → `course_site.py`；方案 3 → `build.py`。

### T6. 课程页字号调节（A5）

- **背景**：单讲有字号三件套（`--fs` 变量 + `zoom` + max-width 反除 + 边界禁用 + 持久化），
  课程页没有（能力不对称）。
- **方向**：照单讲机制（`site.js:255-284`）做一套。**两条实施约束**：
  ① 持久化键名必须带课程专属前缀（如 `course:`）——file:// 下所有本地页面共享 localStorage 域
  （单讲用 `window.DOC_NS` 机制防串，见 `site.js:21-28`）；
  ② 课程页有自己的 `:root` 变量体系，别直接复用单讲类名。
- 暗色模式**独立可选项**，不夹带（KaTeX 公式、徽标、表格都要过一遍，工作量大）。

### T7. 进度看板改造（B6）—— 涉设计稿

- **症状**：状态信息在地图 / 要点 / 进度表三处重复；进度看板独特价值只剩「进度条 + 说明」。

- **注意**：②会动设计稿 §5.1「五区块」结构——**先改设计稿再改代码**，不可擅自改。

### T8. 术语表排序 / 「出现位置」列截断（B5②③）

- **症状（推演）**：术语出现在 10+ 讲时，「出现位置」格换行成多行、行高不均（实测为
